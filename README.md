## Description

This project is a personal portfolio website showcasing the skills and projects of Moe Kyaw Aung, a Senior Android Architect and Technical Founder. It highlights expertise in Android development, architecture, CI/CD, security, and startup building.

## Features ✨

- **Interactive Hero Section:** Dynamic typing effect for the main tagline and eye-catching animations.
- **Smooth Scrolling & Navigation:** Seamless navigation between sections with sticky header.
- **Custom Cursor Effects:** Unique animated cursor for an enhanced user experience.
- **Reveal-on-Scroll Animations:** Engaging animations that trigger as the user scrolls through the page.
- **Detailed Project Showcase:** Comprehensive display of apps with descriptions, user counts, and technology stacks.
- **Architecture Deep Dive:** Visual explanations of multi-module architecture, CI/CD pipelines, and testing strategies.
- **Startup Experience:** Highlights of startup ventures, growth metrics, and the MVP development process.
- **Showreel & Gallery:** Showcase of video content and visual assets.
- **Tech Stack Breakdown:** Clear categorization of technologies used across different domains.
- **Responsive Design:** Fully responsive across all devices and screen sizes.
- **Contact Form:** Integrated form for potential clients or collaborators to reach out.
- **Code Snippets:** Examples of Kotlin code and YAML configurations are highlighted.

## Installation ⬇️

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dev-moe-kyawaung/Moekyawaung-portfolio-website-02.git
   cd Moekyawaung-portfolio-website-02
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```

## Usage ▶️

1. **Start the development server:**
   ```bash
   npm run dev
   ```
   or
   ```bash
   yarn dev
   ```
   This will start a local development server, usually at `http://localhost:5173` (or a similar port).

2. **Build for production:**
   ```bash
   npm run build
   ```
   or
   ```bash
   yarn build
   ```
   This command compiles and bundles the application for deployment.

3. **Preview the production build:**
   ```bash
   npm run preview
   ```
   or
   ```bash
   yarn preview
   ```
   This command serves the built application locally.
